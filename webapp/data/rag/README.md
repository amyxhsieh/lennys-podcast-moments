# Local RAG index (API-only)

Generated by `node scripts/build-embeddings.js` from the repo root.

**Do not commit large binary/index files.** They are gitignored.

Expected outputs after a successful build:

- `chunks.json` — time-window transcript chunks + metadata
- `embeddings.f32` — Float32 row-major matrix (`chunkCount × 512`)
- `manifest.json` — model, dims, content hash, build date
- `episode-embeddings.json` — mean-pooled episode vectors
- `related-episodes.json` — precomputed related episode lists

Requires `OPENAI_API_KEY`. Run after `node scripts/build-data.js`.
